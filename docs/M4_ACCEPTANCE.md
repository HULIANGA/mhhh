## M4.1 工具链与资产契约

2026-09-16 使用系统安装的 Blender 5.2.2 LTS 完成第一份 `.blend → .glb → Godot` 端到端资产导出。本步骤新增：

- Blender 5.2.2 自动发现与严格版本检查，支持 `BLENDER_BIN`、项目 `.tools/` 和 macOS 标准应用位置。
- Apple Silicon macOS 与 Windows x86_64 的项目内 Blender 安装脚本，下载包使用官方 SHA-256 校验。
- Blender 无界面资产生成脚本，同时保存可编辑 `.blend` 源文件与 Godot 使用的 `.glb`。
- 不依赖 Blender 的 GLB 2.0 结构校验，检查网格、骨架、动画、材质和七个稳定挂点。
- Godot 真实导入测试，检查 `Skeleton3D`、`AnimationPlayer`、挂点节点以及循环动画契约。
- `art-export`、`art-check` 两个开发命令；常规 `test` 也会执行已提交资产的结构和 Godot 导入测试。

Godot 首次扫描时会把仓库中的 `.blend` 当作运行时资源，并在 headless 导入中要求编辑器 Blender 路径。最终通过 `art/blender/.gdignore` 明确隔离美术源文件和作者脚本，只让 `assets/models/*.glb` 进入运行时导入及平台构建。

Blender/GLB 源动作 `idle_loop` 在 Godot 中按导入器约定变为运行时动画 `idle`，同时保留循环模式。后续所有 `*_loop` 动作均按同一规则处理，适配层不得直接假设源动作名等于运行时名称。

重复执行 `art-export` 后，GLB 的 SHA-256 保持一致；`.blend` 会因 Blender 保存元数据变化产生不同二进制哈希，因此验收采用结构契约而非 `.blend` 字节一致性。

### 怪物模型尺寸约定

- Blender 以米为单位制作并应用缩放；模型自身应保持 `scale = 1` 导出。
- 日常视觉尺寸可在 `MonsterPresentation.model_scale` 调整，不需要修改玩法 GDScript；角和移动攻击挂点会随模型一起缩放。
- 身体胶囊碰撞体位于 `scenes/monster.tscn`，不会由可见模型自动推导。模型体型明显变化时需要在场景资源中校准半径、高度和位置。
- 追击距离、攻击选择距离和地面提示属于玩法／平衡配置，不随模型自动缩放；只有设计意图改变时才调整。

## M4.4 女性猎人低模、骨架与基础动作

2026-09-17 完成原创简约卡通女性铠甲猎人的第一版低模资产与运行时接入。角色使用银灰短发、浅色分片铠甲、深色内衬、青绿色不对称短披肩和重靴，弱化面部细节且不含面部骨骼。源文件位于 `art/blender/hunter.blend`，运行时使用 `assets/models/hunter.glb`；生成脚本纳入统一 `art-export` 流程。

人形骨架包含根、骨盆、脊柱、胸、颈、头、双臂、双腿及右手 `WeaponSocket`，共导出 `idle_loop`、`run_loop`、`light_attack`、`charge_enter`、`charge_hold`、`charge_release_1`、`charge_release_2`、`charge_cancel`、`dodge`、`hit` 和 `defeated` 十一个动作。Godot 运行时按移动速度播放待机／跑动循环，并按玩法状态的归一化进度采样攻击、蓄力、取消、翻滚、受击和倒地；动画不驱动角色世界位移、伤害窗口或结算。

猎人表现层已移除程序化身体和腿部，改为实例化正式 GLB。大剑通过 `BoneAttachment3D` 真正挂到骨架右手的 `WeaponSocket`，握把会跟随手部动作；资产内部的稳定握持点继续控制剑身姿态，`BladeBase → BladeTip` 继续提供实际命中路径。受击闪色使用每个实例独立复制的材质覆盖，不修改导入资产的共享基础材质；重开会清除受击状态并恢复待机。

HUD 右上角新增 `Stop monster AI / Enable monster AI` 按钮。关闭时会立即取消怪物正在执行的攻击、隐藏攻击提示并停止追击；重新启用后恢复正常决策。该状态在按 `R` 重开时保持，便于连续验收猎人的移动和动作表现。

首次动作验收发现蓄力动作的双手会向下、向身体后方摆动，躯干还会在蓄力时前弯、释放时突然后仰。现已调整 `charge_enter` 与共用蓄力姿态，使右手武器挂点向身体前上方移动，同时骨盆、脊柱和胸部随剑逐渐后仰；释放时躯干快速前倾，剑随动作向前下方砍落。进入动作现在会在一级蓄力阈值处完整结束，再无缝切换到保持动作，避免手部父骨骼提前跳到最终姿态而使大剑瞬移。测试会同时检查握持点高度、前后方向、身体位移以及进入／保持切换时的大剑连续性。普通攻击动作保持原样。

资产结构和 Godot 导入测试通过：模型共 636 个三角面、6 个材质、1 套蒙皮骨架和 11 个动作，符合 15,000 三角面及 6 材质预算；必需骨骼、右手挂点、循环动作和原地动画契约均已验证。M1～M3 全量自动回归 15 组全部通过，连续 10 局重开无状态或节点残留；Web 与 Windows x86_64 release 构建成功。

2026-09-20 由用户完成浏览器人工验收：固定俯视角下的角色朝向、大剑握持、待机／跑动、普攻、蓄力进入与保持、两档释放、取消、翻滚、受击、倒地及重开恢复均符合预期；蓄力时身体随剑逐渐后仰、释放时快速前倾，进入／保持切换时大剑不再瞬移。M4.4 正式完成，后续进入 M4.5。
