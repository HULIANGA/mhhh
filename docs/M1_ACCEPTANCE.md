## 自动检查

运行 `python3 tools/dev.py test`，覆盖：

- 开始前暂停，启动后角色落在真实地面上。
- 实际移动距离符合速度设置，斜向不加速。
- 四个方向的实体边界均能阻挡角色。
- 暂停期间位置不变，清理按住的移动键。
- 检查点按顺序完成，重置清空进度。
- 连续 10 次重置不增加场景节点。

## 浏览器手动验收

在 Chrome 和 Firefox 分别打开本地预览：

1. 加载结束后显示开始页；点击进入，角色才开始接受移动输入。
2. 按 WASD，确认相对屏幕的四个方向正确。
3. 鼠标移到角色四周，确认正面箭头跟随鼠标朝向。
4. 持续朝四周边界行走，不能穿过边界或跌落场景。
5. 依次完成 01、02、03；按 R 后角色和标记全部复位。
6. Esc 暂停后位置保持；切换标签／窗口应暂停，回来后主动继续。
7. 测试 1280×720 和更宽窗口，界面保持可读，指向和画面一致。
8. F1 观察帧率，记录浏览器版本、设备、分辨率和大致范围。

## 当前范围

- 首阶段无攻击、翻滚、怪物和音效；不能用来验收战斗手感。
- 无手机布局和触控，优先桌面 1280×720 及以上窗口。
- 目标为本机浏览器稳定接近 60 FPS，需实测，不提前保证。
- 剩余验收按上表继续记录；不要把内置浏览器的结果等同于 Chrome、Firefox 或 Windows 的通过结果。
